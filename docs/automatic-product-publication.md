# Automated product publication contract

Always start from current GitHub main, not a cached Cloudflare worker or earlier export. A new product cannot be published without an exact supplier item ID, listing URL, supplier variant/configuration, and an inspected original listing photograph. The first approved gallery image is the thumbnail; the same provenance record supplies guide imagery. Never generate a product SVG, stock substitute, lookalike or placeholder. Existing five unsourced items are explicitly text-only until sourcing catches up; do not add further exceptions. Preserve supplierPhotos, existing thumbnails, CSP, and validateProductPhotography() when rebuilding. Before any production deployment, deploy a preview and verify every product's thumbnail and guide image loads and matches its recorded supplier URL, checkouts remain intact, and missing-evidence products have no imagery. Never upload a direct ad-hoc worker from an older local template. All automatic additions must commit to GitHub main and deploy the reviewed commit SHA.
